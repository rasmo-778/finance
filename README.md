# Finance Telegram Mini App

> Современное веб-приложение (Telegram Mini App) для личного учёта финансов с мультивалютным балансом, историей операций и детальной аналитикой.

---

## 📌 О проекте

**Finance Mini App** — это клиентская часть системы учёта финансов, предназначенная для работы внутри **Telegram**. Приложение автоматически авторизует пользователя через криптографическую валидацию `initData` на сервере FastAPI и отображает актуальные транзакции, добавленные через Telegram-бота.

---

## ✨ Основные возможности

- **💳 Главный экран**:
  - Отображение текущего баланса с автоматическим распределением по валютам (`RUB`, `UZS`, `USD` и др.).
  - Раздельный учёт общей суммы доходов и расходов.
  - Быстрый просмотр последних транзакций с автоматическим обновлением.

- **📅 Календарь и фильтрация**:
  - Фильтрация операций по гибким периодам (*Сегодня*, *7 дней*, *Текущий месяц*, *Произвольный диапазон*).
  - Сортировка по типам операций (*Все*, *Только расходы*, *Только доходы*).
  - Безопасное удаление транзакций за последние 7 дней прямо из веб-интерфейса.

- **📊 Аналитика по категориям**:
  - Наглядная интерактивная круговая диаграмма (Donut Chart) со структурой расходов и доходов.
  - Детальный список категорий с процентной долей в бюджете и цветовой индикацией.
  - Мультивалютный переключатель аналитики.

## 🚀 Локальный запуск и сборка

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется локально по адресу `http://localhost:3000`.

> ⚠️ **Обратите внимание:** Приложение рассчитано на запуск внутри Telegram. При открытии в обычном браузере без `Telegram.WebApp.initData` отображается предупреждение о необходимости запуска через Telegram.

### 3. Сборка для Production
```bash
npm run build
```
Готовые статические файлы будут собраны в папку `dist/`.

---

## 🔒 Авторизация и Безопасность

Приложение не требует ввода паролей или логинов. Авторизация происходит автоматически при открытии Mini App в Telegram:
- Строка `window.Telegram.WebApp.initData` передаётся в каждом HTTP-запросе в заголовке `X-Telegram-Init-Data`.
- Бэкенд-сервис (FastAPI) проверяет HMAC-SHA256 подпись Telegram-бота, гарантируя защиту от подделки запросов.
